# 🔐 Random Password Generator

A command-line Python tool that generates strong, random passwords based on user-defined length and character type criteria.

## 📸 Screenshots
![Password Generator Screenshot](password_generator_output.png)

## 🛠️ Built With
- Python 3
- random
- string

## ✅ Features
- User-defined password length (minimum 8 characters enforced)
- Choice of character types: uppercase, lowercase, numbers, symbols
- Requires at least 2 character types selected
- Input validation for invalid lengths or selections
- Option to generate another password without restarting
